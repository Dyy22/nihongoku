# Tata Bahasa

## 1. Bentuk sopan dan bentuk biasa
Sejauh ini kita memakai **bentuk sopan** (です／ます). Di antara teman dan keluarga, orang Jepang memakai **bentuk biasa** (普通形{ふつうけい}).

| Jenis | Sopan | Biasa |
|---|---|---|
| Kata kerja | 行{い}きます | 行{い}く |
| | 行{い}きません | 行{い}かない |
| | 行{い}きました | 行{い}った |
| | 行{い}きませんでした | 行{い}かなかった |
| Kata sifat い | 高{たか}いです | 高{たか}い |
| | 高{たか}くないです | 高{たか}くない |
| | 高{たか}かったです | 高{たか}かった |
| | 高{たか}くなかったです | 高{たか}くなかった |
| Kata sifat な | 静{しず}かです | 静{しず}かだ |
| | 静{しず}かじゃ ありません | 静{しず}かじゃ ない |
| | 静{しず}かでした | 静{しず}かだった |
| Kata benda | 雨{あめ}です | 雨{あめ}だ |
| | 雨{あめ}じゃ ありません | 雨{あめ}じゃ ない |
| | 雨{あめ}でした | 雨{あめ}だった |

!! Bentuk negatif lampau kata benda dan kata sifat な: じゃ なかった. Contoh: 雨{あめ}じゃ なかった.

## 2. Kapan memakai yang mana?
1. **Bentuk sopan**: kepada orang yang baru dikenal, lebih tua, atasan, pelanggan, dan dalam situasi resmi.
2. **Bentuk biasa**: kepada teman dekat, keluarga, dan orang yang lebih muda; juga dalam tulisan seperti buku harian, makalah, dan berita.

!! Kalau ragu, pakai bentuk sopan. Memakai bentuk biasa terlalu cepat bisa terdengar kasar; sebaliknya, orang Jepang biasanya yang lebih dulu mengajak bicara santai.

## 3. Ciri percakapan santai
1. Pertanyaan tanpa か, cukup dengan nada naik: 行{い}く？ (Mau pergi?)
2. だ sering dibuang di akhir kalimat tanya: 元気{げんき}？ (Sehat?)
3. Partikel sering hilang: ご飯{はん}、食{た}べた？ (Sudah makan?)
4. はい／いいえ menjadi **うん／ううん**.
5. Akhiran khusus: ～の？ (bertanya penjelasan), ～よ, ～ね, ～じゃない？

- 明日{あした} 暇{ひま}？ | Besok senggang?
- うん、暇{ひま}だよ。 | Iya, senggang kok.
- いっしょに 映画{えいが}、見{み}に 行{い}かない？ | Mau nonton film bareng?

!! Pria dan wanita kadang memakai kata yang berbeda. Contohnya 僕{ぼく} (aku, biasanya pria) dan akhiran ～わ (biasanya wanita, agak kuno). Di awal belajar, cukup pakai 私{わたし}.

# Percakapan

## Rencana akhir pekan (santai)
Rina dan Mei, teman sekamar di asrama.

メイ: リナ、日曜日{にちようび} 何{なに}か 予定{よてい} ある？ | Rina, hari Minggu ada rencana?
リナ: ううん、特{とく}に ない。どうして？ | Nggak, nggak ada yang khusus. Kenapa?
メイ: 新{あたら}しい カフェ、行{い}ってみない？ パンケーキが すごく おいしいって。 | Mau coba ke kafe baru? Katanya pancake-nya enak banget.
リナ: いいね！ 何時{なんじ}に する？ | Asyik! Jam berapa?
メイ: 11時{じゅういちじ}は？ 混{こ}むから、早{はや}く 行{い}こう。 | Jam 11? Biasanya ramai, jadi ayo pergi lebih awal.
リナ: わかった。楽{たの}しみ！ | Oke. Nggak sabar!

!! 行{い}こう adalah bentuk ajakan santai dari 行{い}きましょう. Bentuk ini dipelajari lebih lanjut di tingkat berikutnya.
